# RobotTesting Web v0.2

PoC bilingüe ES/EN, responsive y lista para GitHub Pages.

## Páginas
- `index.html` — Home
- `services.html` — descripción detallada de servicios
- `academy.html` — curso Playwright + TypeScript
- `about.html` — misión, valores y enfoque
- `contact.html` — formulario PoC (visual; requiere conectar un backend/servicio para enviar)

## Antes de publicar
1. Reemplaza `contacto@robottesting.example`.
2. Agrega LinkedIn/WhatsApp comerciales reales.
3. Revisa textos, precios y condiciones.
4. El formulario es una PoC: conéctalo a un endpoint o proveedor de formularios.
5. Mantén solo tecnologías/servicios que realmente ofrezcas.

## GitHub Pages
Sube el contenido de esta carpeta a la raíz del repo y activa:
Settings → Pages → Deploy from a branch → main → /(root).
